# CEITE Landing Page Design (Google Stitch Spec)

## Overview

A professional SaaS-style landing page for **Computer Science and Information Technology education**. The design emphasizes clarity, hierarchy, and credibility using a **dark mode UI**, **orange–green accent system**, and **Inter font**. Visual style is **sharp and modern** with **no rounded borders** (strict rectangular geometry).

---

## Design System

### Color Palette

* **Background (Primary):** #0D0D0D
* **Surface (Secondary):** #161616
* **Primary Accent (Orange):** #FF7A00
* **Secondary Accent (Green):** #22C55E
* **Text (Primary):** #FFFFFF
* **Text (Muted):** #A1A1AA
* **Borders:** #262626

### Typography

* **Font Family:** Inter (Google Font)
* **Headings:** Semi-bold / Bold (600–700)
* **Body:** Regular (400)
* **Scale:**

  * H1: 56px
  * H2: 40px
  * H3: 28px
  * Body: 16px
  * Small: 14px

### Layout Rules

* Max width: 1200px
* Grid: 12-column layout
* Spacing: 8px base system
* Borders: **1px solid, sharp edges (no border-radius)**
* Shadows: Minimal or none (flat SaaS aesthetic)

## Component Guidelines

### Buttons

* Rectangular
* No border radius
* Primary: Orange background
* Secondary: Transparent with green border

### Cards

* Flat design
* Sharp edges
* Border-based separation (no shadows)

### Icons

* Outline style
* Consistent stroke width
* Use green/orange sparingly

---

## Interaction & UX

* Hover states: color transitions (orange ↔ green)
* Smooth transitions (150–200ms ease)
* Clear visual hierarchy
* Avoid clutter—lean toward SaaS minimalism

---

## Tone & Branding

* Professional
* Technical but approachable
* Future-focused
* Clean and structured (like modern SaaS dashboards)

---

## Notes for Google Stitch

* Use **component-based sections**
* Keep layout modular for reuse
* Emphasize **grid alignment**
* Maintain **consistent spacing tokens**
* Ensure responsive scaling (mobile → stacked layout)
